# QuroChecker

**QuroDev · Discord Username Checker** — a single-file Windows tool.

## Download

Grab the latest `QuroChecker.exe` from the [**Releases**](../../releases/latest) page and double-click it. No other files needed — everything is bundled into the one exe.

## First run

1. Enter your license key
2. Add your proxies and (optionally) a Discord webhook
3. Pick a check mode from the menu

Close anytime with the X button.
